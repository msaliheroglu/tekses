# apps/moderator — Moderatör paneli

**Faz 1'de başlayacak.** Next.js: dalga formu üzerinde söz zamanlama
(LRC içe/dışa aktarma), paralel kue şeritleri, telefon önizleme simülatörü,
paket derleme/yayınlama, QR, katılımcı sayısı ve saat kalitesi ısı haritası,
GO / HOLD / STOP / BLACKOUT düğmeli canlı konsol, otomatik program editörü.
